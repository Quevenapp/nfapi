NFapi / Instalar o cofre

Instalar o cofre na sua conta Cloudflare

O cofre é o seu emissor: guarda o certificado digital A1, recebe os pedidos dos seus sistemas, emite as notas e arquiva os XML. Ele roda na sua conta: ninguém mais recebe o certificado.

Antes de começar

  • Uma conta Cloudflare com o plano Workers Paid (US$ 5/mês), exigido pelo Container que fala com o governo.
  • Uma conta GitHub: o Cloudflare cria nela uma cópia do código do cofre.
  • O arquivo .pfx do seu certificado A1 e a senha dele.
1

Gere o segredo do cofre

O segredo cifra o seu certificado e é a senha da tela de configuração. Ele é gerado aqui, no seu navegador, e não é enviado a lugar nenhum.

Guarde este segredo. Baixe o arquivo e mantenha-o em um gerenciador de senhas ou outro local seguro. Se ele for perdido, será preciso reinstalar o certificado; quem o tiver consegue entrar na configuração do seu cofre.

2

Instale pelo botão do Cloudflare

O botão abre o painel do Cloudflare com tudo preenchido: o Worker, o banco de dados e o armazenamento dos XML.

Deploy to Cloudflare

No formulário que abrir:

  1. Escolha a sua conta Git.
  2. No campo VAULT_SECRET, apague o que estiver lá e cole o segredo que você copiou no passo 1.
  3. Deixe Proteger com Cloudflare Access desligado.
  4. Clique em Implantar e aguarde o build terminar.

Atenção ao preenchimento automático. O navegador pode colocar uma senha salva sua no campo VAULT_SECRET. Limpe o campo antes de colar o segredo.

3

Instale o certificado no cofre

Quando o build terminar, o Cloudflare mostra o endereço do seu cofre (algo como nfapi-cofre.sua-conta.workers.dev). Abra-o acrescentando /setup e entre com o segredo.

  1. Envie o arquivo .pfx e a senha do certificado.
  2. Rode o teste de conexão: ele consulta os serviços de homologação do governo, sem emitir nada.

A produção começa bloqueada: o cofre só emite em homologação até você liberar nessa mesma tela.

4

Crie uma chave de API e emita

Na mesma tela, em Chaves de API, crie uma chave para cada sistema que vai emitir. Ela aparece uma única vez. Com ela, o seu sistema chama o cofre direto:

curl -X POST https://SEU-COFRE.workers.dev/v1/nfse \
  -H "Authorization: Bearer nfapi_SUA_CHAVE" \
  -H "Content-Type: application/json" \
  -d '{
    "ambiente": "homologacao",
    "referencia": "pedido-1001",
    "prestador": { "codigoMunicipio": "3550308",
      "regimeTributario": { "simplesNacional": "me_epp", "apuracaoSimples": 1 } },
    "tomador": { "cnpj": "99888777000166", "nome": "Cliente Ltda" },
    "servico": { "codigoMunicipioPrestacao": "3550308",
      "codigoTributacaoNacional": "010701", "descricao": "Suporte técnico" },
    "valores": { "servico": 1500 },
    "tributacao": { "issqn": { "aliquota": 2 },
      "totalTributos": { "tipo": "percentual_simples", "percentual": 6 } }
  }'

O cofre numera, monta e assina a nota, envia ao governo e arquiva o XML. As notas emitidas aparecem na tela do cofre, com os arquivos para baixar e a opção de cancelar. A referência completa está no README do cofre.

5

Deixe a atualização a um clique

O governo muda regras e leiautes com frequência. Quando sai uma correção, a tela do cofre avisa. Para instalar com um clique, crie o gatilho uma única vez:

  1. No painel do Cloudflare, abra Workers & Pages e selecione o Worker do cofre.
  2. Em Configurações > Compilações > Ganchos de implantação (em inglês, Settings > Builds > Deploy Hooks), clique em Adicionar, dê um nome ao gancho, escolha a branch main e salve.
  3. Copie a URL que aparece abaixo do gancho e cole na seção Atualização da tela do cofre.

A atualização troca só o código. O certificado, as chaves de API e as notas arquivadas continuam onde estão.
