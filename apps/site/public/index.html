NFapi

API open source para emissão de notas fiscais brasileiras: NFS-e pelo Sistema Nacional, NF-e e NFC-e.

A API só emite. O certificado e as notas ficam com você.

Cada emitente instala um cofre na própria conta Cloudflare. É ele que guarda o certificado digital A1, assina os documentos, fala com o governo e arquiva os XML. A API nunca recebe o certificado nem armazena as notas.

Instalar o cofre Código no GitHub

Estado do projeto

Em desenvolvimento. A emissão de NFS-e funciona nos testes automatizados, mas ainda não foi validada de ponta a ponta contra o governo. NF-e e NFC-e ainda não foram implementadas. Não use em produção.

NFapi é open source (MIT).
